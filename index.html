Vous avez déjà un fichier token.txt ?

Ouvrez-le, copiez le token, et collez-le ci-dessous.

Créer un nouveau token :

  1. Allez sur GitHub Settings → Personal Access Tokens
  2. Cliquez "Generate new token (classic)"
  3. Cochez le scope gist
  4. Copiez le token et collez-le ci-dessous
